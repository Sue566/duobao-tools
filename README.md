# 多宝工具箱

该项目提供一个集成多种常用小工具的前端页面，支持主子菜单管理和搜索功能。所有功
能均基于浏览器端 JavaScript 实现，无需后端依赖。页面默认展示全部工具，搜索框可
快速过滤需要的工具。

## 功能
- **主子菜单配置**：通过 `menu.js` 维护工具分类及其层级结构。
- **工具搜索**：在页面上可实时搜索工具名称。
- **常见工具**：包含文本处理、数值转换、日期时间等多种小工具。

## 使用
克隆仓库后直接打开 `index.html` 即可使用，也可以将项目放置在任意静态文件服务器上访问。

## 目录结构
- `index.html`：主页面。
- `style.css`：页面样式。
- `menu.js`：菜单配置文件。
- `tools/`：存放各个工具的脚本文件。

## 内置工具
- 大小写转换
- 文本长度统计
- URL 编码/解码
- Base64 编码/解码
- JSON 格式化
- 进制转换
- 时间戳转换
- 颜色转换

## 贡献
欢迎在 `tools/` 目录下添加更多工具，同时在 `menu.js` 中配置新的菜单项。
